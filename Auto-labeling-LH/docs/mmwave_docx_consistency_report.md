# 毫米波雷达 DOCX 与代码一致性检查

检查来源：`D:\Documents\LH2026\毫米波雷达.docx`  
检查数据：`D:\Dataset\LH_2026-04-27\bag1.1\with_cameras_capture_20260427_151113_mmwave_udp.bin`

## 结论

当前代码与 DOCX 中“毫米波雷达发智能融合处理模块接口”的总体结构一致：

- 每包 `2156 × 32bit = 8624 bytes`
- 包头 64 字、回波 1344 字、地形点 36 字、检测结果 712 字
- 各区起始位置、数组容量和主要数据类型一致
- `bag1.1` 的包头、和路、差路、地形点接口双同步字全部通过检查
- 检测接口有 2 个包的两个尾同步字为 0，这是源 BIN 中的原始异常

## DOCX 与实测数据的差异

DOCX 将包头“距离量程,千米”声明为 `Uint32`。但 `bag1.1` 中该字段稳定为原始字
`0x40800000`：

- 按 `Uint32`：`1082130432`，不可能是千米量程
- 按 IEEE-754 `float32`：`4.0`，符合 4 km 雷达量程

因此代码继续按 `float32` 解析。这是接口文档的数据类型标注错误，不是代码偏移错误。
